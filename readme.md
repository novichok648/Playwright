# Автотесты русскоязычной Википедии на Playwright

Набор сквозных тестов для [Википедии](https://ru.wikipedia.org/). Тест проверяет интерфейс сайта, выполняет поиск статьи «Театр» через поисковую форму, сверяет текст страницы и переходит к разделу «История театра».

## Запуск в Windows PowerShell

```powershell
npm.cmd install
npx.cmd playwright install chromium
npm.cmd test
```

Тест состоит из трёх шагов. После успешного запуска он сохраняет снимок экрана статьи в `screenshots/test-passed.png`.
